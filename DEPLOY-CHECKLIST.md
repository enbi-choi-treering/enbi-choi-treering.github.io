# First public deployment checklist

Before `Commit to main` / `Push origin` in GitHub Desktop:

- [ ] The repository contains only the files from this deployment folder.
- [ ] No CV source PDF, Word/Excel file, grant draft, private notes, or unrelated photos are present.
- [ ] No password, GitHub token, API key, `.env`, private key, or recovery code is present.
- [ ] Only the public profile-photo copy is inside `assets/images/`; the original stays elsewhere.
- [ ] The public photo has no unnecessary GPS/EXIF metadata.
- [ ] `google_scholar` in `_config.yml` points to the intended public Scholar profile.
- [ ] Contact email is intentionally public, or remains blank.
- [ ] Publication links marked `#` have been reviewed; add DOI/journal links when ready.
- [ ] GitHub Desktop's **Changes** list contains nothing unexpected.

Home News displays dates as `YYYY.MM`, although full dates may be stored for sorting. It shows 5 entries initially and reveals 5 more per `Show more` click.
